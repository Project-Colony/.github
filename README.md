This is the community health repository of the [Project-Colony](https://github.com/Project-Colony) organization.
[`profile/README.md`](profile/README.md) is the organization page, and [`.github/FUNDING.yml`](.github/FUNDING.yml) holds the funding links.

These are the defaults for every repository that has none of its own:

| File | What it is |
|---|---|
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Pull request, commit and language rules |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Bug report and feature request forms, and a link to the security policy |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | The checklist from `CONTRIBUTING.md`, filled in on every pull request |

A repository that ships its own `.github/ISSUE_TEMPLATE/` folder or pull request template uses only its own: GitHub does not merge the two.

> **Status:** documentation only. There is no code here, and nothing is released from this repository.

## Privacy

This repository holds documentation only. It runs no code, and collects, stores and sends nothing.
