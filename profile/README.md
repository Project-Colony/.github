<p align="center">
Colony is an ecosystem of small, focused desktop utilities built with Rust.<br/>
Instead of one monolithic tool that does everything poorly, Colony offers a curated set of apps —<br/>
each designed to do one thing exceptionally well, with native performance and beautiful, themeable interfaces.
</p>

&nbsp;

<h3 align="center">🧠 Philosophy</h3>

<p align="center">
<b>One app, one purpose</b> — each Colony tool solves a single problem with clarity and precision.<br/>
No feature bloat, no hidden complexity.
</p>

<p align="center">
<b>Native performance matters</b> — everything is built in Rust.<br/>
Startup is instant, memory usage is minimal, and your CPU stays cool.
</p>

<p align="center">
<b>Beauty is not optional</b> — every app ships with multiple color themes<br/>
(Catppuccin, Gruvbox, Everblush, Kanagawa…) and adapts to your system's dark mode.<br/>
Tools should look as good as they work.
</p>

<p align="center">
<b>Cross-platform by default</b> — Colony targets Windows and Linux from day one.<br/>
The same binary, the same experience.
</p>

&nbsp;

<h3 align="center">🛠 Tech Stack</h3>

<div align="center">

| Layer | Technology |
|:-----:|:----------:|
| **Language** | Rust |
| **GUI frameworks** | Iced, Tauri |
| **Data** | SQLite (via rusqlite) |
| **GPU backends** | NVML (NVIDIA), sysfs (AMD/Intel) |
| **Platforms** | Windows, Linux |
| **Build system** | Cargo workspaces |

</div>

<h3 align="center">🌍 Internationalization</h3>

<p align="center">
Colony and its ecosystem support <b>50 languages</b> with zero-cost static string tables<br/>
compiled directly into each binary. Font selection adapts automatically<br/>
to the active language — no runtime overhead, no external files.
</p>

&nbsp;
